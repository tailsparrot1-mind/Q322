# Vkus Marketplace — адаптивная панель фильтров и проверка размеров окна

Дата: 22.11.2026  
Рабочая база: `tailsparrot1-mind/Q322`, ветка `main`  
Итоговый commit: `876761d7fce5bacf2c6099293fd4b0726d35f462`  
Объект: внутренняя «Доска объявлений» / Marketplace. Не внешняя вкладка «Биржа».

## Что обнаружено при просмотре CI-скриншотов

На первом актуальном снимке доски справа у панели фильтров кнопка «СБРОСИТЬ» располагалась вплотную к границе и частично теряла визуальное пространство. Кроме того, первоначальный smoke test снимал весь виртуальный экран, а не окно приложения, поэтому имена файлов 1920×1080 и 1366×768 сами по себе не доказывали фактический размер окна.

## Исправления

- Панель фильтров теперь адаптивно переносит поле города и действия поиска на вторую строку при ширине внутренней области меньше 1080 px.
- На широкой панели поля остаются в одной строке.
- Кнопка «СБРОСИТЬ» сохранена как отдельный доступный контрол.
- В smoke test добавлена проверка, что кнопка сброса остаётся внутри панели на компактном размере.
- Smoke test теперь устанавливает точную геометрию окна, проверяет фактические размеры Tk-окна и сохраняет снимок именно окна приложения через bounding box.
- Добавлены отдельные снимки доски при 1920×1080 и 1366×768.
- Проверяется возврат тестового объявления после нажатия «СБРОСИТЬ», а также поиск по Enter.
- В workflow Xvfb явно задаётся виртуальный экран 1920×1080.
